# Логика сценариев МПП2 для АМО

Готовая статическая страница для публикации через GitHub Pages.

## Как опубликовать

1. Создать новый репозиторий на GitHub или открыть существующий.
2. Загрузить в корень репозитория файлы из этой папки:
   - `index.html`
   - `mpp2_scenarios_logic.html`
   - `README.md`
3. В GitHub открыть `Settings` -> `Pages`.
4. В разделе `Build and deployment` выбрать:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/root`
5. Нажать `Save`.

Через 1-3 минуты GitHub выдаст публичную ссылку вида:

`https://username.github.io/repository-name/`
